Insert IC into Socket U1

Select a TTL 74-Series digital logic IC to insert into this socket:

7400 14-Pin DIP
Quad 2-Input NAND Gate
Four independent 2-input NAND gates. Pin 14: VCC, Pin 7: GND.
Inputs: 1A,1B,2A,2B... • Outputs: 1Y,2Y...
7404 14-Pin DIP
Hex Inverter (NOT Gates)
Six independent inverter gates. Pin 14: VCC, Pin 7: GND.
Inputs: 1A,2A,3A... • Outputs: 1Y,2Y,3Y...
7408 14-Pin DIP
Quad 2-Input AND Gate
Four independent 2-input AND gates. Pin 14: VCC, Pin 7: GND.
Inputs: 1A,1B,2A,2B... • Outputs: 1Y,2Y...
7432 14-Pin DIP
Quad 2-Input OR Gate
Four independent 2-input OR gates. Pin 14: VCC, Pin 7: GND.
Inputs: 1A,1B,2A,2B... • Outputs: 1Y,2Y...
7486 14-Pin DIP
Quad 2-Input XOR Gate
Four independent 2-input Exclusive-OR gates. Pin 14: VCC, Pin 7: GND.
Inputs: 1A,1B,2A,2B... • Outputs: 1Y,2Y...
74151 16-Pin DIP
8-Line to 1-Line Multiplexer
8 data inputs (D0-D7), 3 select lines (C,B,A), Strobe G̅. True Y & inverted W outputs. Pin 16: VCC, Pin 8: GND.
Inputs: D0..D7, A,B,C, G̅ • Outputs: Y, W
7476 16-Pin DIP
Dual J-K Flip-Flop with Preset & Clear
Two independent negative-edge J-K flip-flops with active-low Preset and Clear. Pin 5: VCC, Pin 13: GND.
Inputs: CLK, J, K, PRE̅, CLR̅ • Outputs: Q, Q̅
7490 14-Pin DIP
Decade & Binary Counter
Contains divide-by-2 and divide-by-5 counters with master reset and set. Pin 5: VCC, Pin 10: GND.
Inputs: CKA, CKB, R0(1), R0(2), R9(1), R9(2) • Outputs: QA, QB, QC, QD
